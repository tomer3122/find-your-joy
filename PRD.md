# Find Your Joy

## Purpose

Find Your Joy is an English-only React gallery that helps people explore dog breeds and save favorites.

## Target Users

People who want to browse dog breeds, find a breed of interest, and keep track of favorite breeds.

## Confirmed Features

- Site logo
- Breed search
- Short About section
- Alphabetically sorted breed gallery
- Fixed warm cream gallery background (`#FFF7ED`)
- Image-first breed cards
- Favorite heart toggle
- Responsive layout
- Breed detail page
- Favorites page

## Constraints

- React, Vite, and TypeScript
- React Router
- Public, keyless Dog CEO API
- Do not use `any`
- Accessibility
